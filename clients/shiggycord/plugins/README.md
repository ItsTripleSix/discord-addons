# ShiggyCord plugins

## Quick install links

Add the raw directory URL for the plugin you want in ShiggyCord's plugin manager.

| Plugin | What it does | Install URL |
| --- | --- | --- |
| [Account Switcher](account-switcher/) | Native-style multi-account switching with active-account notification handling | `https://raw.githubusercontent.com/ItsTripleSix/discord-addons/main/clients/shiggycord/plugins/account-switcher/` |
| [Composer Cleaner](composer-cleaner/) | Hides selected native composer buttons | `https://raw.githubusercontent.com/ItsTripleSix/discord-addons/main/clients/shiggycord/plugins/composer-cleaner/` |
| [Hidden Channels](hidden-channels/) | Shows metadata for inaccessible channels already present locally | `https://raw.githubusercontent.com/ItsTripleSix/discord-addons/main/clients/shiggycord/plugins/hidden-channels/` |
| [Purge Tools](purge-tools/) | Bulk message/reaction cleanup with preview, resume, verification, and pacing controls | `https://raw.githubusercontent.com/ItsTripleSix/discord-addons/main/clients/shiggycord/plugins/purge-tools/` |
| [Quick Mock](quick-mock/) | Alternating-case mock text from slash, reply, or long-press workflows | `https://raw.githubusercontent.com/ItsTripleSix/discord-addons/main/clients/shiggycord/plugins/quick-mock/` |
| [Settings Pins](settings-pins/) | Pins plugin settings into ShiggyCord and can hide existing non-core shortcuts | `https://raw.githubusercontent.com/ItsTripleSix/discord-addons/main/clients/shiggycord/plugins/settings-pins/` |
| [Silent Typing](silent-typing/) | Adds a customizable silent-typing composer toggle | `https://raw.githubusercontent.com/ItsTripleSix/discord-addons/main/clients/shiggycord/plugins/silent-typing/` |

### Purge Tools account-risk notice

Personally, Purge Tools has worked fine for me. Discord can still restrict or ban accounts for activity it considers abusive or automated. **Use it at your own risk. I am not responsible for account restrictions, suspensions, or bans.**
